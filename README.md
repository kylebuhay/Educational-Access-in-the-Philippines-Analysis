# 📊 Educational Access in the Philippines: Analyzing Enrollment Disparities

This project analyzes enrollment disparities in the Philippines from 2010-2021 using the `HistoricalEnrollmentData` dataset. It explores trends across regions, sectors, genders, and grade levels, revealing challenges like urban-rural divides, retention issues, and the impact of the COVID-19 pandemic. Insights aim to guide policymakers in addressing gaps and improving educational equity.

Key features:
- Techniques: Descriptive analysis, clustering with K-Means, predictive modeling with XGBoost
- Findings: Regional disparities (NCR vs. CAR), public-private enrollment trends, gender imbalances, and retention challenges in Grades 9-10.

The project provides actionable recommendations for resource allocation, infrastructure improvement, and policies to bridge gaps in educational access.

**Tools:** NumPy, Pandas, Matplotlib, Seaborn, SciKit-Learn, XGBoost, and Tableau
